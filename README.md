# TV Auto

TV Auto 是一款面向 Android TV、手机和平板的轻量级电视直播浏览器。它不依赖传统 IPTV 源列表，而是把网络直播网页整理成频道，让用户用接近电视的方式浏览、切换和管理网页直播内容。

当前版本：**v6.0**  
包名：`mulin.tvauto.pro`  
最低系统：**Android 4.4**

---

## 核心特点

- 内置默认频道，首次安装即可直接使用
- 将网络直播网页接管为沉浸式播放界面，适合日常“开机看电视”
- 支持遥控器、键盘和触摸屏操作
- 支持扫码进入手机管理页，电视负责播放，手机负责整理
- 支持频道新增、删除、恢复默认、清空、批量导入和导出
- 支持高级用户为特定站点添加自定义脚本，并导入或导出脚本配置
- 支持“原始网页”模式，遇到登录、授权或特殊页面时可临时退出播放接管

---

## 适合谁使用

TV Auto 更适合希望把常看的直播网页整理成频道的人：

- 只想打开软件就看，不想频繁维护传统 IPTV 源
- 希望电视端尽量简单，把复杂输入放到手机上完成
- 偶尔需要为特殊网站做个性化适配的高级用户

如果某个站点本身要求登录、强制交互、限制播放或页面结构发生变化，TV Auto 也无法保证永久可用；这类情况可以尝试“原始网页”模式或自定义脚本。

## 功能概览

### 播放与切台

- 默认使用内置频道列表
- 上 / 下键切换频道
- 数字键可直接跳转到指定频道
- 频道加载期间显示半透明 TVAuto 提示层，弱网或断网时仍能看到原页面状态

### 频道管理

- 电视端可手动新增单个频道、删除当前频道、检测更新
- 打开频道管理窗口后，左侧会显示二维码和局域网地址
- 手机扫码后可在同一 Wi‑Fi 下打开管理页
- 手机管理只在频道管理窗口打开期间启用，关闭窗口后自动停止

### 手机管理页

手机端支持：

- 查看当前频道列表
- 新增频道
- 删除频道
- 恢复默认频道
- 删除全部频道
- 批量导入频道
- 导出当前频道列表为 `.txt`
- 检测更新
- 添加、编辑、删除用户脚本
- 导入或导出用户脚本 `.json`

### 原始网页模式

如果某个网站需要登录、授权或临时操作原网页：

- 在全屏播放时连续按两次左键，可进入原始网页模式
- 也可以在频道管理窗口中点击 `原始网页`
- 原始网页模式会暂停 TV Auto 的页面接管，重新显示站点自身页面
- 页面会默认缩放，顶部常驻提示 `当前为原始网页，按返回回到播放`
- 按返回键即可回到正常播放模式

> 原始网页模式更适合触屏或接入鼠标后使用。纯遥控器对复杂网页的操作能力有限。

## 遥控器操作

| 按键 | 功能 |
| --- | --- |
| 上 / 下 | 切换上一频道 / 下一频道 |
| OK / 右 | 打开右侧频道列表 |
| 左 | 连续按两次进入原始网页模式 |
| 菜单 | 打开频道管理 |
| 数字键 | 直接输入频道号 |
| 返回 | 播放模式下双击退出；原始网页模式下返回播放 |

---

## 频道导入格式

频道导入和导出均使用纯文本 `.txt`，每个频道以英文分号结尾：

```txt
"频道名称","频道地址";
```

示例：

```txt
"CCTV-1 综合","https://tv.cctv.com/live/cctv1/";"江苏卫视","https://live.jstv.com/";
```

导出的文件名会自动带上实际日期，方便备份和区分版本。

---

## 用户脚本

用户脚本用于给特定站点提供专属适配能力。

- 匹配项可以填写完整 URL，也可以填写域名或 URL 片段
- 当当前页面命中用户脚本时，会优先执行用户脚本，而不是默认脚本
- 用户脚本与频道列表独立保存，可单独导入或导出
- 适合高级用户自行处理特殊站点布局、播放器选择或页面样式

---

## 使用须知

- 默认频道仅作示例用途，不保证长期可用，也不保证适用于所有地区
- 请用户自行核实并添加合规频道
- TV Auto 只负责整理和展示用户访问的网页内容，不提供直播内容本身
- 使用过程中请遵守当地法律法规，开发者不承担因用户自行添加内容而产生的法律责任
