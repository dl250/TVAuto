# TV Auto

TV Auto 是一款使用 WebView 的轻量级电视直播软件。操作简单，可将网络视频直播资源整理为频道列表，在 Android TV、手机和平板上提供一致的沉浸式播放体验。

---

## 功能概览

- 内置默认频道，首次启动即可使用
- 支持电视端手动添加频道
- 支持扫码进入手机管理页，在手机上新增、删除、导入和导出频道
- 理论兼容大部分 16:9 视频网页
- 支持遥控器和触摸屏操作

---

## 使用须知

- 默认频道列表仅作示例用途，不保证可用性与合法性
- 请用户自行核实、添加合规的频道
- 使用过程中请遵守当地法律法规，开发者不承担任何法律责任

## 快速使用

### 电视端

- 按遥控器 **菜单键** 打开频道管理
- 可直接在电视端手动新增单个频道、删除当前频道或检测更新

### 手机端管理

- 在频道管理窗口左侧扫描二维码
- 手机端支持：
  - 新增频道
  - 删除频道
  - 批量导入 `.txt`
  - 导出当前频道列表为 `.txt`
  - 检测更新
- 手机管理只在频道管理窗口打开期间可用，关闭窗口后会自动停止

### 批量导入格式

导入导出均使用纯文本格式，以英文分号结尾：

```txt
"频道名称","频道地址";
```

示例：

```txt
"CCTV-1 综合","https://tv.cctv.com/live/cctv1/";"江苏卫视","https://live.jstv.com/";
```
